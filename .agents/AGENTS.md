# Antigravity Agent Guidelines

- **No Implementation Plans:** Do not create `implementation_plan.md` or enter planning mode for code changes unless explicitly requested by the user. Perform changes directly.
- **No Scratch Files:** Do not create scratch files, temporary scratchpads, or unneeded artifact files.
- **No Browser Launch / Verification:** Never launch the browser subagent (`browser_subagent`) or attempt to open/control the browser to test or verify code. Present code edits directly in the chat or terminal.
